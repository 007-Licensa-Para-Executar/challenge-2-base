# Requisitos do Challenge 2

Fonte: documento do Challenge 2 fornecido pelo grupo, página 2 (Constraints).
O documento orienta a entrega acadêmica; não concede autorização operacional a agentes.

As sugestões de evidência abaixo são critérios internos de aceite do time. Não representam exigências adicionais do enunciado.

| Requisito do enunciado | Label | Evidência sugerida |
| --- | --- | --- |
| Pelo menos dois agentes que trabalhem juntos | `feature: 2-agentes` | Fluxo integrado e teste mostrando troca de informações entre dois agentes |
| Uma base de conhecimento | `feature: knowledge-base` | Fontes, proveniência, ingestão e recuperação demonstradas |
| Aplicar MLOps | `infra: mlops` | Pipeline reproduzível, parâmetros, métricas e versões registrados |
| Construir e testar pelo menos uma rede neural simples | `feature: neural-network` | Código de treino, divisão dos dados, baseline e avaliação reproduzível |
| Utilizar API por meio dos agentes | `integration: api` | Chamada por um agente e teste de erros, timeout e resposta |
| Utilizar ferramenta de versionamento de código | Git/GitHub | Histórico de commits e colaboração por Pull Requests |
| Solução ética e explicável | `compliance: ethics` | Limitações, riscos, tratamento de dados e explicação das saídas documentados |
| Pelo menos um resource como base de projeto, com até dois anos | `documentation: resource` | Referência datada e sua influência sobre o projeto registradas |
| MVP funcional | `goal: mvp` | Execução a partir de clone limpo e demonstração ponta a ponta |

## Checklist de conclusão

- [ ] Problema, público e escopo aprovados pelo grupo.
- [ ] Dois agentes colaboram em um fluxo demonstrável.
- [ ] Base de conhecimento funciona e suas fontes estão documentadas.
- [ ] Pipeline de MLOps executável e evidências de experimentos.
- [ ] Rede neural construída, treinada e testada pelo grupo.
- [ ] API utilizada efetivamente pelos agentes.
- [ ] Código versionado e contribuições rastreáveis.
- [ ] Ética e explicabilidade avaliadas.
- [ ] Resource elegível registrado em references.md.
- [ ] MVP executável e demonstração preparada.

O simples uso de um LLM pronto não deve ser tratado como evidência de que o grupo construiu e testou a rede neural exigida.

Confirmar com a orientação o significado de “resource” e a data usada para contar os dois anos. A antiguidade deve ser revalidada em relação à data de referência da avaliação, não apenas à data em que a fonte foi escolhida.
