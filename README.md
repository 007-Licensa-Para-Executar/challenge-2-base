# Challenge 2 - MVP Base

Base privada do time de seis pessoas para o **Challenge 2: Bem-estar**.

A ideia, o público, as tecnologias e as responsabilidades ainda serão definidos pelo grupo. Este repositório prepara a colaboração e a rastreabilidade das exigências; ainda não contém um MVP.

## Organização

| Diretório | Finalidade |
| --- | --- |
| `agents/` | Agentes e sua coordenação |
| `knowledge_base/` | Ingestão, fontes e recuperação de conhecimento |
| `mlops/` | Pipelines, experimentos e avaliação |
| `models/` | Código de modelos, treinamento e avaliação |
| `docs/` | Requisitos, planejamento, decisões e evidências |

Não versionar credenciais, dados pessoais reais, bases privadas ou pesos de modelos grandes.

## Começar

1. Ler [requisitos e critérios de aceite](docs/requirements.md).
2. Definir a proposta usando [o roteiro de oito semanas](docs/roadmap.md).
3. Registrar as fontes em [referências](docs/references.md).
4. Trabalhar em branches e abrir Pull Requests conforme [CONTRIBUTING.md](CONTRIBUTING.md).
5. Consultar [as pendências de infraestrutura](docs/infrastructure.md).

Não há dependências, comandos de execução ou pipeline de aplicação definidos nesta etapa. Eles devem acompanhar a primeira implementação executável.
